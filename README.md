# Homebrew Tap for cirrus-tools

This repository contains Homebrew formulae for [cirrus-tools](https://github.com/cirrus-tools) projects.

## Usage

```bash
brew tap cirrus-tools/tap
brew install gcx
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [gcx](Formula/gcx.rb) | GCloud Context Switcher |
